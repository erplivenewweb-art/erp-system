# SEO and Accessibility

Homepage metadata includes a static title, description, relative canonical strategy, OpenGraph-ready text shell and `index,follow`. No final domain or social image is invented. `/design-system` retains its explicit `noindex,nofollow,noarchive` metadata.

Accessibility foundations:

- exactly one H1 and ordered H2/H3 section hierarchy
- semantic sections, articles, lists, links and existing shell landmarks
- meaningful labels for every local media placeholder
- text content independent of images
- 44px or 48px actions; mobile hero CTAs stack full-width
- native `details`/`summary` FAQ through the shared Accordion
- visible focus ring confirmed in the browser
- no autoplay, automatic carousel or essential animation
- reduced-motion rules remove decorative transforms; all styling uses theme semantic tokens
- axe homepage and full-shell foundations pass with jsdom color-contrast calculation excluded

Real media alt text, contrast with final photography, screen readers, 200% zoom and final structured-data eligibility remain Phase 3J/content-owner checks.
