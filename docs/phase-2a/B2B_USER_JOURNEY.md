# B2B Journey

| Stage | Need | Experience | Gate |
|---|---|---|---|
| Landing | Understand manufacturer proposition | Range, capability, terms overview, proof | Public-safe only |
| Registration | Create business identity | Progressive form with save/resume | Separate dealer auth |
| Verification | Submit evidence safely | Protected references, clear purpose/retention | No raw docs in profile |
| Approval | Know status and next step | Timeline, missing-info requests, support | No pricing before approval |
| Dashboard | See actionable business state | Quotes, orders, credit visibility, alerts | Live entitlement |
| Catalogue | Browse efficiently | Dense optional list/grid, filters, download metadata | Approved dealer |
| Pricing | Understand slabs/MOQ | Unit/total, breakpoints, expiry | Authorized price list |
| Bulk cart | Build order quickly | Quantity entry, validation, optional future upload | Versioned recalculation |
| Quotation | Negotiate durably | Revision comparison, terms, messages | Immutable revisions |
| Approval | Accept/reject confidently | Summary, expiry, authorized actor | ETag/idempotency |
| Order/dispatch | Track operational progress | Snapshots and shipment timeline | Safe ERP projection |
| Repeat | Reuse prior intent | Copy lines then revalidate | Never reuse expired price |

Dealer analytics show commerce-safe aggregates only. Credit terms are view-only entitlements, not accounting balances. Bulk upload is a future UX specification with template validation and preview; it is not implemented.
