# Luxury Design Language

The visual system is quiet, warm and material-led. Ivory provides gallery space; near-black ink supplies precision; silver is structural, not low-contrast body text; vermilion is a rare cultural accent; antique gold is reserved for editorial detail, never confused with product material.

Grid: 4 columns mobile, 8 tablet, 12 desktop; 16/24/32px gutters; content max 1440px and reading measure 720px. Mobile begins at 320px with no horizontal scroll. Breakpoints are content-driven reference points at 480, 768, 1024, 1280 and 1536px.

Radius is restrained: 4–8px controls, 16px editorial cards, pill only for chips. Elevation uses borders/space before shadows. Dark mode is optional and later: it must use charcoal, not pure black, preserve product color accuracy, never auto-invert imagery and meet contrast independently.

Icons are 1.5px optical-line symbols with clear labels for ambiguous actions. Illustration uses fine linework inspired by tools and forms, not clichéd motifs. Photography is primary.

Motion explains hierarchy: fade/translate under 240ms, editorial transitions up to 420ms, no parallax essential to comprehension. Reduced-motion removes spatial transitions and autoplay. Loading uses stable-ratio image placeholders and text skeletons; empty/error states state what happened, preserve user work and give one clear recovery action.
