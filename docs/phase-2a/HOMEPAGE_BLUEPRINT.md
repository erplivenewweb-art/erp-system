# Homepage Blueprint

Priority bands: P0 orientation/trust, P1 discovery, P2 proof, P3 retention. Mobile keeps the same narrative but removes nonessential decoration.

| Section | Purpose / priority | Desktop | Tablet | Mobile | Conversion goal | CMS owner | SEO value |
|---|---|---|---|---|---|---|---|
| Hero | State promise, show signature craft / P0 | 60/40 editorial image-copy | Balanced split | Full image then concise copy | Explore signature collection | Brand editor | H1 and brand proposition |
| Collections | Establish product worlds / P0 | 3 editorial tiles | 2-column | Horizontal snap/list | Enter a collection | Merchandiser | Collection links |
| Featured Products | Immediate consideration / P0 | 4-up calm grid | 3/2-up | 2-up | View product | Merchandiser | Product internal links |
| Manufacturing Story | Prove maker status / P1 | Wide film + narrative | Stacked | Poster + short proof | Learn how it is made | Brand editor | Expertise/entity context |
| Workshop | Show place/tools honestly / P1 | Photo essay | 2-up | Vertical story | Build trust | Content editor | Original informative content |
| Artisans | Human craft with consent / P2 | Portrait/story cards | 2-up | One story at a time | Deepen affinity | Content editor | People/process context |
| Purity Promise | Explain verified facts / P0 | Proof panel | Full width | Short checklist | Reduce material doubt | Compliance/content | Trust terms |
| Packaging | Show ownership/gifting / P2 | Still life + details | Split | Image then bullets | Increase confidence | Merchandiser | Packaging/care queries |
| Testimonials | Social proof / P1 | 3 cards | 2 cards | Manual carousel/list | Validate choice | Review moderator | Review content |
| Trust Badges | Summarize evidenced policies / P0 | Inline row | Wrap | 2-column | Reduce anxiety | Compliance | Supporting trust |
| Categories | Alternate discovery / P1 | Visual taxonomy | Grid | List/cards | Browse intent | Merchandiser | Category links |
| Custom Orders | Invite high-intent enquiry / P1 | Editorial CTA | Full width | Compact CTA | Start custom enquiry | Service/content | Custom search intent |
| Wholesale | Separate dealer path / P1 | Dark restrained band | Full width | Clear portal card | Register/sign in dealer | Dealer content owner | Wholesale landing link |
| Instagram | Current visual proof / P3 | Curated 6-up | 4-up | 2-up | Social follow | Social editor | Minimal; no index dependence |
| YouTube | Long-form craft / P2 | Featured video | Responsive | Poster-first | Watch story | Video editor | Video metadata/transcript |
| Blog | Education and culture / P2 | 3 articles | 2-up | List | Read guide | Editorial | Topic authority |
| FAQ | Resolve objections / P1 | 2-column accordion | Single | Single | Continue confidently | Support/content | FAQ content/schema if eligible |
| Newsletter | Permission-based retention / P3 | Compact inline | Full | Stacked | Subscribe | Marketing | None direct |
| Footer | Trust/service/navigation / P0 | Multi-column | Condensed | Accordions | Find support/policy | Content owner | Crawlable internal links |

Instagram/social embeds must not block performance or consent. FAQ structured data is used only when current search-engine eligibility and content parity are confirmed.
