```text
┌──────────────────────────────────────────────────────────────────┐
│ DEALER BRAND   Catalogue Quotes Orders Support     Account       │
├──────────────────────────────────────────────────────────────────┤
│ Welcome back                  Approval: Active · Price valid      │

│ Open quotes 3 │ Orders 8 │ Dispatches 2 │ Credit terms: View     │
├──────────────────────────────────────────────────────────────────┤
│ [Start bulk order] [Request quotation] [Repeat prior order]       │
├──────────────────────────────────────────────────────────────────┤
│ Recent quotations              Recent orders                     │
│ Ref / revision / expiry        Ref / status / dispatch           │
├──────────────────────────────────────────────────────────────────┤
│ Recommended wholesale catalogue / MOQ-aware products             │
└──────────────────────────────────────────────────────────────────┘
```

Analytics are commerce-safe aggregates. Credit terms show entitlement, never accounting balances.
