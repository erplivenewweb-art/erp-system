# Cart and Checkout Preview Wireframe

```text
┌──────────────────────────────────────────────────────────────┐
│ Your cart                                                    │
├────────────────────────────────────┬─────────────────────────┤
│ Item image / title / options       │ Summary                 │
│ Availability · quote freshness     │ Subtotal                │
│ Qty [− 1 +]  Remove  Save          │ Tax wording             │
│                                    │ Delivery estimate       │
│ Item 2 ...                         │ Total / refreshed time  │
│                                    │ [Checkout preview]      │
├────────────────────────────────────┴─────────────────────────┤
│ Packaging · delivery · returns reassurance                   │
└──────────────────────────────────────────────────────────────┘
```

Price refresh explains differences before proceeding. Preview is explicitly non-binding and creates no payment or ERP action.
