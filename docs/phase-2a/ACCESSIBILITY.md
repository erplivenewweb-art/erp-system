# Accessibility Strategy

Target WCAG 2.2 AA across storefront, dealer and CMS experiences; critical purchasing/account flows aim higher where practical. Accessibility acceptance includes automated checks plus keyboard, screen reader, zoom, contrast, reduced-motion and touch testing with disabled users where possible.

Semantic landmarks, one clear H1, logical headings and meaningful link names support navigation. Focus order follows reading order; focus is never trapped except correctly managed modal/drawer; opening/closing restores focus. Skip links reach content/search. All functions work without pointer and at 200% zoom/reflow at 320 CSS px.

Focus indicators are at least 2px/3:1 and never removed. Touch targets are 44px minimum. Errors are identified in text, associated to fields, summarized with focus and preserve input. Live regions are restrained. Authentication avoids cognitive tests where possible.

Images have purposeful alt; complex craft diagrams have descriptions. Video has accurate captions and transcript; audio description is considered for visual-only meaning. Autoplay is avoided. Reduced-motion disables parallax, shimmer and nonessential transforms. Large text and OS contrast preferences retain functionality.

Prices, availability, ratings, timelines, quantity/MOQ and dealer status never depend on color/icon alone. Bengali and other scripts require screen-reader, font shaping and language-attribute testing.
