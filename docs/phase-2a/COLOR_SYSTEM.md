# Color System

| Role | Value | Use |
|---|---|---|
| Brand Ink | #151311 | Primary text, dark surfaces |
| Gallery Ivory | #F8F4EC | Main canvas |
| Crafted Silver | #B9BDC2 | Dividers, decorative detail |
| Silver Dark | #666B70 | Approved large/detail use |
| Vermilion | #8C2F2B | Rare brand emphasis |
| Antique Gold | #A27B43 | Editorial accent only |
| Success | #276749 | Confirmed states |
| Warning | #8A5A12 | Caution/aging state |
| Error | #9B2C2C | Error/destructive state |
| Focus Blue | #1C65A6 | Visible keyboard focus |

Body text uses ink or neutral 700 on ivory/white. Silver and antique gold do not carry small text or essential state alone. Every semantic state combines color with icon and text. Links are underlined in body copy. Selected/focus/hover are distinct.

Target WCAG 2.2 AA: 4.5:1 normal text, 3:1 large text and UI boundaries, 3:1 focus indicator against adjacent colors. Key purchase and form flows should aim for AAA text where practical. Contrast is retested for every token/theme combination and over imagery; image text requires a controlled opaque/gradient surface.
