# Static Design Validation

Run with Python 3:

```powershell
python docs/phase-2a/validation/validate_design.py
```

The dependency-free check verifies required documents, ten exact diagrams, at least eight wireframes, 100+ design tokens, 46 component rows, homepage coverage and explicit mobile, accessibility, SEO, performance, CMS, ERP-isolation, B2C, B2B and future-platform language. It rejects runtime-looking HTML, CSS, JavaScript, TypeScript, SQL and environment files inside Phase 2A.

It opens no network, database, ERP process, package tool, runtime or deployment configuration.
