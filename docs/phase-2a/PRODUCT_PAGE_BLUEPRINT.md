# Product Page Blueprint

## Information order

Breadcrumb → gallery → identity/title → customer-safe material facts → retail price or approved dealer quote → availability/freshness → options/size → quantity/MOQ → primary action → delivery/returns → trust → story/craft → packaging/care → reviews → FAQ → related/recent.

Desktop uses a 7/5 gallery/purchase split with the purchase summary sticky only while it fits. Tablet moves to balanced columns. Mobile uses gallery first, compact identity/facts and an accessible bottom purchase action that never obscures content.

Gallery supports portrait and detail imagery, video captions/transcript and a future 360 view with static fallback. Zoom is explicit and keyboard accessible. Weight, purity and size are labeled as customer-safe ERP-derived facts with appropriate variability/verification wording; no barcode or internal branch data.

Retail price shows currency, tax wording, quote freshness and recalculation. Wholesale indicator is a sign-in/eligibility cue only; MOQ and slabs appear only to approved dealers. Availability uses coarse status and last-updated language. Custom order and WhatsApp are secondary, contextual actions.

Packaging, care, delivery and returns use concise summaries with policy links. Reviews mark verified only through safe purchase verification. Related products avoid endless loops; recently viewed requires consent/local handling. SEO content remains useful and visible, not hidden keyword copy.
