# Component Library

## Global rules

Every interactive component has default, hover, active, focus-visible, disabled, loading, error and success states where relevant. Touch targets are at least 44×44px; primary actions generally 48px high. Labels remain visible; icons never replace essential text. Components accept content expansion, localization, 200% zoom and reduced motion.

## Inventory and UX rules

| Component | Core UX rule |
|---|---|
| Button | One primary action per region; verbs describe outcome; loading preserves width |
| Input | Persistent label, hint before error, autocomplete/input mode |
| Search | Predictive but keyboard complete; recent search is consensual |
| Card | Entire-card click only with one destination; nested actions independent |
| Product Card | Image, title, safe price/quote cue, availability, wishlist; no false urgency |
| Dealer Card | Business/workflow summary; confidential facts suppressed |
| Table | Real headers, caption, responsive card alternative; never color-only |
| Badge | Non-interactive metadata |
| Status Chip | Text + icon + semantic state; unknown safe fallback |
| Price Block | Currency, price type, tax wording, expiry/refresh; wholesale gated |
| Availability Indicator | Coarse status + freshness language, no exact stock |
| Breadcrumbs | Current page announced; structured-data parity |
| Pagination | Cursor/load-more with retrievable URLs where SEO requires |
| Tabs | Roving keyboard model; not used for required sequential steps |
| Accordion | Native semantics; headings remain navigable |
| Carousel | Manual controls, pause, no forced autoplay; all content reachable |
| Drawer | Mobile secondary surface; focus trapped and restored |
| Modal | Reserved for blocking decisions; Escape/close and focus restore |
| Toast | Supplemental; never sole confirmation; pausable timeout |
| Alert | In-flow, titled, action-oriented, announced appropriately |
| Timeline | Ordered status history with timestamps and current state |
| Review Card | Rating, date, verified label rules, moderation-safe content |
| Rating | Numeric alternative; star input keyboard operable |
| Form | Logical groups, progress for long forms, preserve entered data |
| Validation Message | Field-linked, plain language, summary links on submit |
| Skeleton Loader | Mirrors final layout; no shimmer under reduced motion |
| Image Gallery | Stable aspect, thumbnails, zoom, keyboard/swipe parity |
| Video Gallery | Captions/transcript, poster, no autoplay with sound |
| Comparison Card | Same attribute order, missing-data honesty |

| Footer | Trust, support, policies, channels and locale—not link dumping |
| Header | Brand, primary navigation, search/account/cart; calm sticky behavior |

| Navigation | Current location and clear Wholesale separation |
| Mobile Bottom Navigation | Maximum five destinations; labels always visible |
| Desktop Navigation | 5–7 primary items; dealer portal distinct |
| Sticky Elements | Activate after context; respect viewport and zoom |
| Quantity Price Breaks | Explain threshold and recalculated unit price |

| Quote Expiry | Absolute/localized time plus refresh action |
