# B2C Journey

| Stage | User need | Primary design response | Trust/performance guard |
|---|---|---|---|
| Visit | Understand brand quickly | Hero promise + signature craft | Fast poster, clear H1 |
| Browse | Discover without expertise | Collections/categories and editorial cues | Stable cards, no jargon |
| Search | Find form/use/material | Suggestions, allowlisted filters, typo recovery | Keyboard complete |
| Product | Judge beauty and suitability | High-detail media, facts, care, policy | Safe freshness and proof |
| Wishlist | Save consideration | Clear saved state; guest continuity | Consent/privacy |
| Cart | Confirm choices | Editable quantities, quote/freshness summary | Preserve state |
| Checkout preview | Know total and delivery | Address, price/tax/delivery preview | No surprise fees |
| Order | Commit once | Idempotent confirmation language | No duplicate action |
| Tracking | Reduce uncertainty | Human status timeline and support | Safe provider data |
| Review | Share useful evidence | Accessible rating/media flow | Verified rules/moderation |
| Repeat | Re-enter with context | Care, reorder/discovery | No manipulative personalization |

Critical moments: first product confidence, price refresh, address errors, payment uncertainty, delivery delay and return request. Each preserves user work and offers a clear human support path.
