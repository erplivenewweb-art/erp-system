# SEO UX

One descriptive H1 per page; H2s define meaningful sections; headings never exist for visual size alone. Breadcrumbs match visible hierarchy and structured data. Internal links connect collections, products, care, manufacturing, guides and policies with descriptive text.

Recommended URL patterns: `/products/{slug}`, `/collections/{slug}`, `/categories/{slug}`, `/journal/{slug}`; locale strategy requires approval. Slug changes create durable redirects. Facets/search are canonicalized or noindexed by explicit policy to prevent crawl traps.

Commerce owns titles, descriptions, canonical, robots intent, OpenGraph and social cards. Product/organization/breadcrumb/article/video/FAQ structured data is emitted only when visible content and current eligibility rules support it; price/availability must reflect safe fresh data. No hidden SEO copy or fabricated reviews.

Product sections answer material, size/use, craft, care, packaging, delivery and returns genuinely. Collection pages include editorial context. Blogs earn authority through original workshop knowledge, named review and internal links. XML sitemap inclusion follows publication/indexability.
