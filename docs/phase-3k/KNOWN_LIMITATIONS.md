# Known Limitations

- Static UI only: no authentication, persistence, commerce API, ERP, pricing, inventory, orders, payments, shipping, dealer approval or CMS publication.
- Media, reviews, customers, addresses, orders, quotations, SEO and policies are synthetic placeholders pending approval.
- No production domain/canonical host or published structured data.
- Automated contrast testing cannot resolve CSS custom properties in JSDOM; visual token audit passed.
- OS/browser/assistive-technology lab coverage and legal/security/content approval remain release-deployment prerequisites.
- Generated directory sizes are not network transfer or Core Web Vitals measurements.
