# Luxury Visual Language

Personality: quiet confidence, material precision, warm Indian craft and modern restraint. Luxury cues are proportion, truthful detail, typography, service clarity and negative space—not metallic gradients, excessive animation or ornamental clutter.

Spacing uses a 4px base with 24–32px component rhythm and 80–128px desktop editorial sections. Align text, image edges and actions to a shared grid; deliberate asymmetry may create editorial tension but never break task order. One visual anchor per viewport.

Shape language is mostly rectilinear with 4–8px controls, 16px editorial cards and pill only for chips. Surfaces use ivory/white/charcoal, hairline borders and space before shadows. Texture is photographic/paper-grain at ≤3% opacity, never behind small text. Glass is reserved for transient navigation over controlled imagery with opaque fallback.

Light is soft directional and gallery-like. Dark is charcoal/material, never glossy black. Gradients are subtle tonal atmosphere, not fake metal. Minimalism removes competition, not information. Hierarchy uses scale → space → weight → color in that order. Reading rhythm alternates concise task areas with slower craft story; commerce facts remain immediately reachable.
