# Responsive Behaviour

Mobile 320+: 4 columns/16px gutters, single-task source order, 44px targets and safe-area actions. Tablet 768+: 8/24px, paired editorial cards and optional persistent filters where space permits. Laptop 1024+: 12/24–32px with moderated whitespace. Desktop 1280–1536+: 12/32px, max 1440px; content does not stretch indefinitely.

Foldables respond to available segments/insets without placing key action across hinge. Smart displays are read-oriented future surfaces, not purchase assumptions. Pointer hover enhances only. Landscape, split screen, 200% zoom and virtual keyboard remain functional.

Typography, spacing and media crop interpolate within safe clamps. Sticky elements disable when they cannot fit. Dealer/CMS density scales through view choice and column priority, not smaller inaccessible text.
