# Media Art-Direction Cards

Each planned asset receives a card with: purpose, page/region, audience, narrative beat, subject, aspect/crops, lighting, background/props, camera angle, depth of field, color target, alt/caption/transcript, consent/rights, retouch boundary, output widths/formats, LCP/lazy policy, expiry and owner.

Required cards: hero, collection, product primary, macro, scale/context, packaging, workshop, artisan, process, dealer range, custom order, journal, social/reel and video poster.

A card is rejected if it implies false material, scale, included contents, certification, workshop evidence or cultural context.
