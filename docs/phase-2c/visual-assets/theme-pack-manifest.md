# Theme Pack Manifest

Every festival/seasonal theme design package declares:

- Unique name/version and base-token compatibility.
- Allowed accent/texture/media overrides.
- Explicit forbidden semantic, focus, grid, type and product-image overrides.
- Locale, audience and company/storefront scope.
- Start, end and automatic fallback.
- Cultural, brand, legal, accessibility and performance approvals.
- Preview screenshots/specs for mobile/tablet/desktop/dark mode.
- Asset rights/expiry and rollback owner.

A missing or invalid field prevents activation in any future implementation.
