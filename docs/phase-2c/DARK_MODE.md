# Dark Mode

Dark mode is charcoal gallery ambience, not inverted light mode. Canvas #121110, surface #1D1B19, raised #272421, text #F6F2EA, muted #C4BEB4, border #49443F and silver #C8CCD0. Focus and semantic states are independently retested.

Product images are not inverted; use approved alternate backgrounds/crops if light masters create glare. Cards rely on surface steps/borders, not heavy shadows. Header/navigation remain legible over media. Dealer/CMS density uses stronger row separators and text contrast.

User choice overrides system; no flash during theme resolution in future implementation. All pages remain complete in either theme. Dark mode never changes price, availability, identity or publication semantics.
