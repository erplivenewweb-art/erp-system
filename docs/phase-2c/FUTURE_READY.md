# Future Design Readiness

Android/iPhone use the same semantic tokens and screen priorities with native controls/navigation where accessibility improves. PWA preserves brand offline but never caches private price/order truth. Dealer app/tablet add compact density tokens and bulk interactions without changing product identity. Admin/CMS uses operational clarity over decorative luxury.

AI Assistant appears as a clearly labeled optional support/discovery surface, cites current content, shows uncertainty and respects visibility. Marketplace/export consume channel renditions and locale/currency/script adaptations, not alternate core design. Right-to-left and additional Indian-script support require typography/layout validation.

Tokens use semantic roles, so themes/platforms map values without redesign. Any new mode must pass contrast, product-color, performance and component-state validation.
