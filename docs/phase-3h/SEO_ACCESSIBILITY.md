# SEO and Accessibility

`/wholesale` is index/follow with relative canonical and OpenGraph-ready metadata. Dealer registration, login and private portal screens use noindex/no-follow. Every page has one H1.

Accessibility includes named dealer navigation, labelled registration/login/quotation fields, visible focus, native FAQ disclosures, semantic tables/captions/row headers, focusable overflow region, disabled upload semantics, status empty states and 44px controls. Landing/dashboard axe checks found zero violations after replacing an initially nested main landmark with a neutral wrapper.

No unsafe HTML, authentication, secret, external script, upload handler, ERP/internal route or network call was added.
