# Phase 3H — Static Dealer Portal

Phase 3H adds a public wholesale introduction and a complete presentation-only `/dealer/*` portal covering registration, login, dashboard, quotations, bulk enquiries, catalogue, pricing/terms, KYC, orders, downloads and support.

There is no authentication, dealer record, API, ERP, database, upload, quotation engine, pricing engine or persistence. The phase passes 78 tests, 47-page build, all guards, audit and four responsive browser viewports. Phase 3I was not started.
