# Phase 3G — Static Customer Account

Phase 3G adds a presentation-only customer dashboard, account navigation, orders/detail, addresses, profile, security and notifications under `/account/*`. There is no authentication, customer identity, API, ERP, database, persistence or live order data.

Seven static/SSG account screens pass 66 tests, production build, all guards, audit and four responsive browser viewports. Phase 3H was not started.
