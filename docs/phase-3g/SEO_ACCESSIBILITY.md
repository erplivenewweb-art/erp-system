# SEO and Accessibility

All account pages are noindex/no-follow and use relative canonical placeholders where applicable. Each page contains exactly one H1 and semantic section headings.

Accessibility foundations include a named account navigation, keyboard-operable horizontal mobile navigation, visible focus, labelled forms, native choices, 44px controls, semantic definition lists, `aria-current`-ready routing structure, named ordered timeline and status-based empty states. Automated axe checks for dashboard and profile found zero violations with JSDOM contrast disabled.

No unsafe HTML, authentication, secret, ERP/internal route, external script or network integration was introduced.
