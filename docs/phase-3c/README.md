# Phase 3C — Public Layout, Header, Navigation and Footer

Phase 3C implements only the reusable public storefront shell under `storefront/`. It adds the semantic root shell, sticky luxury header, desktop and mobile navigation, accessible mobile drawer, shared footer, newsletter UI, social/contact links and a floating WhatsApp action. The `/` route remains a scaffold placeholder; Phase 3D homepage work has not started.

Evidence is stored only in `docs/phase-3c/evidence/`. No API, persistence, authentication, CMS, commerce operation, ERP route or deployment integration exists.
