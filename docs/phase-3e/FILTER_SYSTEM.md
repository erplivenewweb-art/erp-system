# Filter System

The reusable filter panel exposes labelled native selects for category, purity, weight, size, price range, availability and sorting. Sorting choices cover Featured, Newest, Name, Weight and a clearly pending Price option.

Controls are intentionally UI-only. They do not mutate URLs, call APIs, filter server data or persist choices. Native controls preserve keyboard and touch behavior, and every control has an explicit associated label. Mobile browser verification selected `Name` and retained a visible focus outline.
