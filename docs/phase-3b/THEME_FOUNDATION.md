# Theme Foundation

Light is the server-rendered default on the root document, avoiding hydration mismatch. Semantic variables define surfaces, text, border, focus, disabled and component roles.

Dark readiness is a complete semantic override under `data-theme="dark"`; the showcase applies it locally without changing global persistence. Festival and seasonal attributes expose only safe accent hooks. No final theme switcher, cookie, customer preference or festival pack is implemented.

Reduced motion globally collapses transitions/animations. High-contrast compatibility relies on semantic variables, native controls, visible borders and non-color state labels; forced-colors requires later browser validation. Theme state never changes product facts or accessibility semantics.
