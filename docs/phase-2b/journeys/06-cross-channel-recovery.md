# Cross-Channel Recovery Journey

Failure detected → preserve entered/draft state → explain safe outcome (failed, pending or unknown) → offer bounded retry or status refresh → show correlation/reference → provide human support → reconcile authoritative status → notify user → resume exact task.

Payment/integration timeouts never appear as success or definite failure until reconciled. A user can start on mobile and resume on desktop through account-owned state, not tracking pixels or exposed internal IDs.
