# Dealer Lifecycle Journey

Discovery → eligibility → account → business/GST references → protected evidence → review → approval/information request → dashboard → authorized catalogue → bulk cart → quote → revision negotiation → acceptance → staged order → dispatch → repeat → credit visibility → analytics.

At every transition show owner, current state, required next action, expected timing only when approved, support, and immutable history. Approval, price and credit gates fail closed. Rejection/suspension language is respectful, reasoned and appeal-aware where policy permits.
