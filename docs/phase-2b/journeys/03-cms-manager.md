# CMS Manager Journey

Need identified → select structured content type → draft → add approved media/alt/rights → SEO and link checks → preview mobile/tablet/desktop → switch locale/audience → accessibility/performance checks → submit review → changes/approval → schedule/publish → monitor → new version/unpublish/archive.

The manager never edits ERP facts. Preview makes dealer visibility unmistakable. Publish is version-checked and audited; errors preserve draft.
