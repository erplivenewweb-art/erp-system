# Future Mobile User Journey

Deep link/launch → public discovery or PKCE sign-in → native search/filter → product/gallery → wishlist/cart/draft → checkout/quote handoff → biometric confirmation only where policy supports → push notification with opaque reference → fetch current detail → tracking/support.

Offline mode allows public content and drafts only; it never promises current price, availability, credit or order acceptance. Accessibility follows OS text, contrast, reduce-motion and screen-reader settings.
