# CMS UX

CMS navigation covers homepage builder, banners, collections, categories, products/merchandising, media, blogs, FAQ, policies, dealer content, SEO, announcements, campaigns and festival themes.

Builder uses structured approved modules—not arbitrary layout code. Every module shows content requirements, mobile/tablet/desktop preview, locale/audience, contrast/alt/caption status, SEO impact and performance estimate. Media manager shows rights, crops, renditions and usage.

Workflow: Draft → Review → Changes Required/Approved → Scheduled/Published → New Version/Unpublished → Archived. Preview can switch public/customer/dealer and must prevent wholesale leakage. Publish requires current version, required fields, link validation and role permission. ERP facts remain read-only projections and cannot be edited in CMS.
