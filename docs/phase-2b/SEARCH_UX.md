# Search UX

Autocomplete opens after meaningful input, announces result count, supports arrows/Enter/Escape and groups products, collections, categories and guides. Suggestions include spelling correction and approved popular searches without revealing personal/dealer activity.

Results preserve query, use allowlisted filters/sorts and readable removable chips. Mobile filters open a focus-managed drawer; desktop uses a rail. URL state supports sharing/back. No-results explains, suggests corrections/categories and custom enquiry without inventing inventory.

Dealer search adds authorized MOQ/price/availability columns and efficient quantity input; public search cannot query wholesale fields. Analytics records pseudonymous query, result count, filter/sort and click/zero-result outcome under retention/consent policy—never raw sensitive terms indefinitely.
