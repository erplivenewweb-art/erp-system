# Master User Journeys

## B2C lifecycle

Guest discovery → search/category/collection → product evaluation → wishlist or cart → checkout preview → future payment → order confirmation → tracking → review → repeat purchase → future loyalty → future referral.

Identity is progressive: browsing, search and wishlist intent do not force registration; account value is explained at preservation/checkout moments. Price/availability changes are explained before commitment. Payment uncertainty never produces a false confirmation.

## B2B lifecycle

Wholesale landing → dealer identity → progressive application → evidence references → approval timeline → dashboard → restricted catalogue/bulk search → MOQ-aware cart → quotation → negotiation/revisions → authorized acceptance → staged order → dispatch → repeat order → credit terms → commerce-safe analytics.

A login is not approval. Price and catalogue entitlement are checked continuously. Revisions and accepted terms remain immutable.

## Supporting actors

Guest: public discovery and recoverable local intent. Logged-in customer: self-service orders/profile/returns/reviews. Dealer: organization-scoped tasks. CMS manager: draft/review/preview/publish. Support executive: least-privilege customer-safe case context. Future mobile user: same states and public IDs through native navigation.
