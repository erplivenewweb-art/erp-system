# Accessibility UX

Target WCAG 2.2 AA with disabled-user review. All pages work keyboard-only, screen-reader, touch, voice/zoom and at 320 CSS px/200% zoom. Logical landmarks/headings and skip links support navigation. Focus follows DOM reading order, is visible at 3:1, never lost and restores after modal/drawer.

Controls have accessible names, 44px targets and non-color state. Forms use persistent labels, autocomplete, grouped instructions, field errors and focusable summary while preserving input. Authentication avoids inaccessible cognitive tests. Status, price, MOQ, rating, timeline and charts have text alternatives.

Media has decision-useful alt, captions/transcripts and no autoplay sound. Reduced motion removes nonessential animation. Large text does not obscure sticky/bottom actions. Bengali/locale content has correct language, shaping and screen-reader testing.
