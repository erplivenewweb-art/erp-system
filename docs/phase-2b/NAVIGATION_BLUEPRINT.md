# Navigation Blueprint

Desktop: slim optional announcement, 80px header, 5–7 primary destinations, utilities for search/account/wishlist/cart, distinct Wholesale entry. Mega menu groups curated collections/categories/craft content; it opens by explicit action, supports keyboard, safe pointer dismissal and no promotion overload. Sticky header compacts after meaningful scroll and never hides anchors.

Mobile: header holds menu, brand, search/cart. Drawer contains full IA; bottom navigation has at most five labeled destinations—Home, Discover, Search, Wishlist, Account—with cart kept visible in header. Safe-area and keyboard do not obscure actions.

Breadcrumbs are visible, linked, structured-data consistent and horizontally wrap rather than scroll. Footer groups Shop, Craft, Service, Wholesale, Policies and Contact. Dealer/customer navigation shows only authorized tasks. CMS navigation organizes Content, Catalogue, Media, Campaigns, Dealer Content, SEO, Preview and Publishing. Native apps map the same hierarchy to tabs/stacks and deep links.
