# Micro-interactions

Buttons depress subtly (80–160ms) and loading preserves label width. Hover never reveals essential-only content. Wishlist/cart update optimistically only when rollback is clear; confirmation is inline plus optional toast. Success uses restrained check/summary, not confetti. Error shakes are prohibited; errors appear in-flow with focus/summary.

Validation occurs after blur or submit, not every keystroke except constraints. Page transitions preserve context and stay under 240ms. Images crossfade only after stable placeholder. Search suggestions appear without layout shift. Accordions use height/opacity only where reduced motion permits. Tabs update focus/current state. Dropdowns use native/listbox patterns and close predictably.

Every motion has a static equivalent; announcements are screen-reader appropriate and never duplicate.
