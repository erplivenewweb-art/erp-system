# Performance UX

Maintain Phase 2A field targets: LCP ≤2.5s, CLS ≤0.1, INP ≤200ms at p75 representative mobile. Page budgets: critical CSS ≤20KB compressed, initial first-party JS ≤50KB interaction-critical/≤150KB total, third-party ≤50KB reviewed, critical fonts ≤100KB, LCP image usually ≤200KB, initial images ≤700KB.

Search suggestions should appear within 150ms for cached/local response and useful remote results within 500ms under target conditions; typing remains responsive. Filter/sort updates preserve controls and use progressive results.

Cache published content/media with versioned URLs/ETags; never shared-cache private prices/accounts. Prioritize LCP, reserve media dimensions, lazy-load below fold, paginate/virtualize long dealer lists accessibly and poster-gate social/video. Performance errors degrade to usable text and core navigation.
