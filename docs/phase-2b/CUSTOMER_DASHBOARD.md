# Customer Dashboard UX

Dashboard hierarchy: active order/tracking → tasks/alerts → order history → wishlist → returns/reviews → account utilities. Orders have accessible timelines and immutable item/address/price summaries. Wishlist shows current price/availability with explicit refresh.

Addresses use clear default/edit/archive state; profile separates identity, communication and consent. Notifications are filterable and link to their source. Returns explain eligibility without promising outcome. Review prompts appear only for eligible delivered items.

Coupons show eligibility/expiry without dark patterns. Reward points and referral are **future-only**: balances, expiry, anti-abuse, tax and terms require approval. They must not dominate support or order access.
