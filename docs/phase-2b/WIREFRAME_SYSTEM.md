# Wireframe System

The canonical page catalogue is `wireframes/page-catalog.json`; 36 Markdown wireframes provide human review. Frames describe hierarchy and behavior, not visual polish or implementation.

Every page uses four mobile columns, eight tablet and twelve desktop from Phase 2A. Mobile ordering is the source order; larger layouts may compose columns without changing meaning. Common zones are skip link, header/context, breadcrumb where hierarchical, H1/task summary, primary content, supporting proof/help, CTA, footer/bottom navigation.

Wireframe notation: brackets are actions/inputs; bordered regions are layout zones; arrows show progression, not automatic navigation. Private pages never expose CMS-controlled transactional data. Loading/empty/error/success are first-class states, not overlays added later.
