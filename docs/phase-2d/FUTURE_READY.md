# Future Readiness

PWA adds public offline/drafts and isolated service worker only after approval. Android/iPhone/dealer apps consume shared contracts/tokens and PKCE identity, not web internals. Localization uses message/catalogue fields, BCP 47, script-aware fonts and locale routes; currency remains quote-driven.

Export and marketplace use adapters/channel renditions without changing core product IDs. AI search/assistant operates through authorized retrieval, cites facts, labels uncertainty and cannot invent price/stock/purity/policy. Recommendations use consent/minimization and safe visibility.

Voice search is an alternate input to the same search contract. Multi-brand uses host-derived company/brand scope, semantic theme/content mappings and isolation tests—not runtime tenant input. Every future capability is gated, additive and separately approved.
