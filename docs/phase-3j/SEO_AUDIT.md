# SEO Audit

Public homepage/catalogue/wholesale routes have titles, descriptions, relative canonicals where applicable, OpenGraph-ready metadata and one H1. Root metadata now supplies an accurate manufacturer-led description plus OpenGraph and Twitter summary-card fields without inventing a domain.

Search/compare, cart/checkout/account, dealer-private and CMS routes use appropriate noindex strategies. Dynamic catalogue routes generate static metadata. `/design-system` remains noindex.

Structured-data fields remain placeholders because no approved production claims exist. Internal links use planned relative routes and no production domain is embedded.
